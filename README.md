# 🚀 Featured Projects

## 🔐 Privacy-Preserving Fine-Tuning of Multimodal Models

**Master's Thesis**

A research project investigating locally hosted MLLMs for clickable UI detection in enterprise web applications.

**Core technologies:**
`Qwen2.5-VL` · `PEFT` · `LoRA` · `RAG` · `FAISS` · `KubeAI` · `Ollama` · `Kubernetes` · `PyTorch`

**Key work:**
- Compared multiple multimodal models and input modalities.
- Built local MLLM inference using KubeAI and Ollama.
- Developed a two-phase FAISS-based RAG pipeline.
- Built a sanitized-data PEFT/LoRA fine-tuning pipeline.
- Evaluated memorization, conservative behaviour, and adversarial data-extraction risks.
- Investigated the trade-off between model performance, privacy, compute, and deployment complexity.
